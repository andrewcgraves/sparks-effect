# AGENTS.md

The instructions for agents working in this repository are in
[`CLAUDE.md`](CLAUDE.md) at the root, which covers the repo map, the root
`make` commands, pull request rules and what agents never do. Each service has
its own `CLAUDE.md` with rules for everything under it: read
[`api/CLAUDE.md`](api/CLAUDE.md), [`worker/CLAUDE.md`](worker/CLAUDE.md) or
[`website/CLAUDE.md`](website/CLAUDE.md) before working in that directory.
